# Plan 03-01: DimensionRule Divider & Selected Work Section

## Goal
Build the `DimensionRule` section divider and the `SelectedWorkSection` (`components/sections/SelectedWorkSection.tsx`) displaying 3 `ProjectCard` components (`components/ui/ProjectCard.tsx`). Cards feature monochrome geometric placeholder rectangles with a visible "PHOTO TBC" badge and scroll-triggered stroke-draw overlay reveals.

## Requirements
- **HOME-01**: Selected work section preceded by DimensionRule divider, presenting 3-4 featured project cards.
- **HOME-02**: Project card component with image cover, meta, scroll-triggered stroke draw overlay, and desktop hover scale/underline animation.

## Proposed Changes

### 1. Seed Typed Project Data (`content/projects.ts`)
- Define typed project schema with:
  ```ts
  export interface Project {
    slug: string;
    title: string;
    discipline: 'Architecture' | 'Interior' | 'Landscape' | 'Product';
    location: string;
    year: string;
    isPlaceholder: boolean;
    description: string;
    coverPlaceholder: string;
  }
  ```
- Seed 3 obvious placeholder projects:
  - `placeholder-01`: "Placeholder Project 01", Architecture, "Location TBC", 2026, `isPlaceholder: true`
  - `placeholder-02`: "Placeholder Project 02", Interior, "Location TBC", 2026, `isPlaceholder: true`
  - `placeholder-03`: "Placeholder Project 03", Landscape, "Location TBC", 2026, `isPlaceholder: true`

### 2. Build `components/ui/ProjectCard.tsx`
- Props: `project: Project`, `index: number`.
- Structure:
  - Container with `overflow: hidden; cursor: pointer;`.
  - Media wrapper with 4:3 or 16:10 aspect ratio:
    - Monochrome geometric placeholder canvas/SVG with grid pattern and centered `PHOTO TBC` badge in mono font.
    - SVG sketch outline overlay (`pathLength="1"`, `stroke: var(--ink)` or `var(--red)`).
  - Card meta below:
    - Project Title in Instrument Serif with red underline span (`.title-underline`).
    - Discipline and Location in DM Mono caps (`0.14em` tracking).
- Animations (in `gsap.context()`):
  - Scroll enter (`top 80%`, `once: true`):
    - Sketch outline draws (0.9s, `power2.out`).
    - Media reveals bottom-up via clip-path (`inset(100% 0 0 0)` &rarr; `inset(0)`, 0.8s).
    - Meta text fades and slides up.
  - Hover (desktop &ge;769px):
    - Media container scales to `1.03` over 0.5s.
    - Red underline draws under project title.

### 3. Build `components/sections/SelectedWorkSection.tsx`
- Render `DimensionRule` divider at the top with value `4.2 M` (left-to-right draw on scroll).
- Section header:
  - Heading: "Selected work" in Instrument Serif.
  - Link: "All work →" linking to `/work` in DM Mono caps.
- Responsive grid:
  - Desktop (&ge;821px): 3-column or responsive grid.
  - Mobile (&le;820px): 1-column stacked cards.
