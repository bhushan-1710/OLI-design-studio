# Plan 03-02: ProcessSection (Horizontal Scrub & Mobile Stack)

## Goal
Build the `ProcessSection` component (`components/sections/ProcessSection.tsx`) illustrating the studio's design workflow ("How a project moves.") through 4 architectural drafting vignettes. Pinned horizontal scroll on desktop (`+=300%`, `scrub: 1`), collapsing to an unpinned vertical stack on mobile (≤820px) with single-trigger drawing on enter.

## Requirements
- **HOME-03**: Process section with pinned horizontal scroll on desktop (travel = (panels - 1) × viewport width, `end: +=300%`, drawings complete during panel scroll).
- **HOME-04**: Process section responsive mobile fallback (≤820px) stacking panels vertically with single-trigger drawing on enter.

## Proposed Changes

### 1. Create Process Vignette SVG Drawings
- Create 4 dedicated SVG drafting vignette components or embedded SVGs:
  - `01 Sketch`: Organic conceptual curves, site boundary polygon, north arrow glyph, "CONCEPT BRIEF" note.
  - `02 Develop`: 2D architectural floor plan with room partition lines, door swing arcs, and dimension tick marks ("6.40 M").
  - `03 Build`: Isometric structural frame, column grid lines, and concrete hatch lines.
  - `04 Handover`: Clean elevation drawing with red "HANDED OVER" stamp and key handover dimensions.
- All drawing paths include `pathLength="1"` for stroke-draw animation.

### 2. Build `components/sections/ProcessSection.tsx`
- Layout:
  - Section header: "How a project moves." in Instrument Serif.
  - Tracker indicator: 4-stage pills/dots indicating current progress.
  - Panels container (`.process-panels-track`): 4 panels (`01 Sketch`, `02 Develop`, `03 Build`, `04 Handover`).
  - Each panel contains:
    - Stage number & title in DM Mono caps.
    - Stage description paragraph (verbatim from `content.md`).
    - Vignette SVG drawing container.
- Responsive Motion via `gsap.matchMedia()` inside `gsap.context()`:
  - **Desktop (`min-width: 821px`):**
    - Pinned to top: `start: "top top"`, `end: "+=300%"`, `pin: true`, `scrub: 1`.
    - Horizontal translation: `xPercent: -100 * (panels.length - 1)` with `ease: 'none'`.
    - Each vignette drawing draws during its panel's active visibility window.
  - **Mobile (`max-width: 820px`):**
    - Container is NOT pinned. Panels flow vertically with clean gap.
    - Each panel's drawing animates once as it enters viewport (`top 75%`).
  - **Reduced Motion (`prefersReducedMotion()`):**
    - No pinning; horizontal scrub disabled; all vignette drawings fully drawn immediately.

## Verification Steps
1. On desktop (1280px): scroll into Process section; verify section pins smoothly and translates horizontally across all 4 stages.
2. Verify vignette drawings complete during each panel's progress window.
3. On mobile (390px): verify section is NOT pinned; panels stack vertically; vignette drawings trigger on scroll enter.
4. Verify under `prefers-reduced-motion` that horizontal scrub and pin are bypassed.
5. Run `npm run build` to confirm static export succeeds.
