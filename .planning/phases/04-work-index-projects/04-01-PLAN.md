# Plan 04-01: Typed Project Schema, Validation & Work Index

## Goal
Establish the validated project content architecture with build-time `isPlaceholder` protection, seed 4 distinct placeholder projects covering all studio disciplines (Architecture, Interior, Landscape, Product), and build the filterable Work Index page (`/work`, Sheet A-02) with 2-column desktop / 1-column mobile grid, instant filter chips, and URL query parameter sync (`/work?type=...`).

## Requirements
- **WORK-01**: Typed project data model (`/content/projects.ts`) enforcing `isPlaceholder: boolean` flag, `cover`, `brief`, and ≥3 images at build time, blocking unflagged placeholder data from production.
- **WORK-02**: Seed 3+ obviously fake placeholder projects ("Placeholder Project 01", "02", "03", "04", "Location TBC") with `isPlaceholder: true` and zero invented details.
- **WORK-03**: Work index page (`/work`, Sheet A-02) with responsive 2-column desktop / 1-column mobile grid.
- **WORK-04**: Instant discipline filter chips with URL query param sync (`/work?type=...`) without page reload.

## Proposed Changes

### 1. Project Schema & Build-time Validation (`content/projects.ts`)
- Enhance `Project` interface:
  ```ts
  export type Discipline = 'Architecture' | 'Interior' | 'Landscape' | 'Product';

  export interface Project {
    slug: string;
    title: string;
    discipline: Discipline;
    location: string;
    year: string;
    area?: string;
    brief: string;
    isPlaceholder: boolean;
    coverImage: string;
    images: string[]; // ≥ 3 images required
    drawingSvg?: string; // Optional SVG elevation/plan linework for sketch scrub
  }
  ```
- Implement `validateProjects(projects: Project[]): void` function exported from `content/projects.ts` that runs at module import and in a dedicated build script:
  - Asserts that every project has non-empty `slug`, `title`, `discipline`, `location`, `year`, `brief`.
  - Asserts that `coverImage` is provided.
  - Asserts `images.length >= 3`.
  - Asserts that if project details are placeholders (e.g. title starts with "Placeholder" or location is "Location TBC"), `isPlaceholder` MUST be `true`.
  - If validation fails, throws a descriptive Error that halts the build.
- Seed 4 obvious placeholder projects:
  - `placeholder-project-01`: "Placeholder Project 01", Architecture, "Location TBC", 2026, `isPlaceholder: true`
  - `placeholder-project-02`: "Placeholder Project 02", Interior, "Location TBC", 2026, `isPlaceholder: true`
  - `placeholder-project-03`: "Placeholder Project 03", Landscape, "Location TBC", 2025, `isPlaceholder: true`
  - `placeholder-project-04`: "Placeholder Project 04", Product, "Location TBC", 2026, `isPlaceholder: true`

### 2. Work Index Page (`app/work/page.tsx` & `components/work/WorkGallery.tsx`)
- Page setup with `SheetFrame` and `SheetTitleBlock sheetNumber="A-02" title="WORK INDEX" scale="1:100"`.
- Client component `WorkGallery.tsx` wrapped in `Suspense` (for `useSearchParams()`):
  - Discipline filter chips: `All`, `Architecture`, `Interior`, `Landscape`, `Product` with count badges.
  - Active chip styling: solid red fill or red border + mono font.
  - Click updates URL without full page reload via `window.history.pushState` or `router.replace('/work?type=...', { scroll: false })`.
  - Synchronizes on mount with URL search param `type` (case-insensitive).
  - Empty filter state: "Nothing here yet. Try another discipline." in DM Mono.
  - Responsive Grid:
    - Desktop (≥769px): 2 columns with generous architectural drafting gutters (`var(--space-8)` / 32px).
    - Mobile (≤768px): 1 column.
  - Uses `ProjectCard` component linking to `/work/[slug]`, with full-card clickable area and 2px red outline focus ring.
