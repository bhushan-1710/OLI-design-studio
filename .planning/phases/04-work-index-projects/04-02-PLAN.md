# Plan 04-02: Project Detail Template & Sketch-to-Photo Scrub

## Goal
Build the dynamic project detail route (`app/work/[slug]/page.tsx`, Sheet A-03+), static export parameter generator (`generateStaticParams`), the signature scroll-scrubbed `SketchScrub` component pinned for `+=150%`, process and outcome gallery sections, and next-project navigation with project enquiry CTA.

## Requirements
- **WORK-05**: Project detail template (`/work/[slug]`, Sheet A-03+) with title, meta, 2-3 sentence brief, process drawings/photos, outcome gallery, and next-project link.
- **WORK-06**: Sketch-to-photo scroll-scrub component pinned for `+=150%` (`scrub: 0.7`), fading linework from 0-50% and revealing full color photo by 100%.

## Proposed Changes

### 1. Dynamic Route Setup (`app/work/[slug]/page.tsx`)
- Implement `generateStaticParams()` to statically export all projects from `content/projects.ts`.
- Compute dynamic sheet number: `A-03` for project 1, `A-04` for project 2, etc.
- Render within `SheetFrame` and `SheetTitleBlock`:
  - `sheetNumber`: `A-03` (or corresponding index)
  - `title`: Project title in mono caps
  - `scale`: `1:50` or `1:100`
- Section 1: Project Header
  - Project title in large Instrument Serif (`clamp(32px, 5vw, 64px)`).
  - Metadata row in DM Mono caps (`Discipline · Location · Year · Area`).
  - Project brief paragraph in elegant serif typography (2-3 sentences).

### 2. Signature Sketch-to-Photo Scrub Component (`components/work/SketchScrub.tsx`)
- Client component leveraging GSAP ScrollTrigger:
  - Pinned container (`pin: true`, `end: '+=150%'`, `scrub: 0.7`).
  - Dual-layer stack:
    - Bottom layer: Full-color outcome photo / rendering with realistic architectural lighting and materials.
    - Top layer: Architectural drafting SVG linework with construction guides and dimension markers.
  - Scrub timeline:
    - 0% - 30%: Linework visible in sharp ink (`--ink`), subtle dimensions draw in.
    - 30% - 70%: Ink lines fade and color wash dissolves into photo.
    - 70% - 100%: Linework drops to 0 opacity, full photo emerges with 1.02 subtle scale settle.
  - Progress tracker or status pill indicating "DRAFTING / OUTCOME" during scrub.
  - `prefers-reduced-motion` handling: No pin, displays final photo with a clean linework toggle button.

### 3. Process Drawings & Outcome Gallery
- Process grid:
  - 2-column or 3-column drafting cards with plan/elevation wireframes and site sketches.
  - Caption in DM Mono caps (e.g. `FIG 01 — SCHEMATIC PLAN`, `FIG 02 — MATERIAL STUDY`).
- Outcome gallery:
  - Alternating full-width and 2-column photo cards with clean drafting sheet borders and `PHOTO TBC` badges.

### 4. Next Project Navigation & CTA
- Next project footer bar:
  - "Next project →" link with project title and discipline chip, wrapping around to project 1 from the last project.
  - "Planning something similar? Enquire" secondary button linking to `/contact?type=${project.discipline.toLowerCase()}`.

## Verification Steps
1. Run `npm run build` to verify `generateStaticParams` pre-renders all `/work/[slug]` routes (`/work/placeholder-project-01`, `02`, `03`, `04`).
2. Open `http://localhost:3005/work/placeholder-project-01` in browser:
   - Verify SheetTitleBlock displays `SHEET: A-03`.
   - Verify large serif title, mono metadata, and brief render cleanly.
   - Scroll down to `SketchScrub`: verify container pins smoothly for `+=150%`, linework fades as photo dissolves in.
   - Verify Process and Outcome gallery render with drafting borders.
   - Click "Next project →": verify instant navigation to `/work/placeholder-project-02` with Sheet A-04.
3. Test at 390px mobile viewport: verify layout stacks gracefully and scrub operates without overflow or jank.
