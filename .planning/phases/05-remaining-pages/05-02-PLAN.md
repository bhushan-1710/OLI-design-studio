# Plan 05-02: Contact Page (Sheet A-05) & 4-Field Enquiry Form

## Goal
Build the Contact page (`app/contact/page.tsx`, Sheet A-05) with direct contact channels (real `mailto:` email, non-link text for unconfirmed WhatsApp/phone) and an accessible 4-field enquiry form (`components/contact/EnquiryForm.tsx`) featuring client-side blur validation, input preservation on error, double-submit protection, abort timeout, Web3Forms integration, demo mode banner when key is missing, and animated Stamp on verified `success: true`.

## Requirements
- **PAGE-03**: Contact page (`/contact`, Sheet A-05) with headline, direct email link, and non-link placeholder text for WhatsApp/phone.
- **PAGE-04**: Enquiry form with exactly 4 fields (Name, Phone/WhatsApp, Project type, Message), honeypot anti-spam (`botcheck`), visible labels, no placeholder attributes, loose phone validation, double-submit protection, inline validation, and success state displaying animated Stamp.
- **PAGE-05**: Static export form integration wired to Web3Forms client-side submission with provider JSON `success: true` verification; demo mode banner when key is missing in development; build fails if key is missing in production (`OLI_PRODUCTION=1`).

## Proposed Changes

### 1. Build `components/contact/EnquiryForm.tsx`
- Form fields (exactly 4 visible fields + 1 hidden honeypot):
  1. **Name** (`input[type="text"]`, required)
  2. **Phone / WhatsApp** (`input[type="tel"]`, required, validation regex `/^[\d\s+\-()]{7,20}$/`)
  3. **Project type** (`select`, options: Architecture, Interior, Landscape, Product, Not sure yet, pre-selected via `useSearchParams().get('type')`)
  4. **Message** (`textarea`, required)
  5. **Honeypot** (`input[name="botcheck"]`, hidden via CSS + `tabIndex={-1}`)
- Accessibility & UX:
  - Every field has a visible `<label>` element with `htmlFor` pointing to input `id`.
  - **Zero `placeholder=` attributes** on inputs.
  - Architectural drafting underline inputs (`border: none; border-bottom: 1.5px solid var(--ink); border-radius: 0; background: transparent;`).
  - Red outline on `:focus-visible`.
- Validation & State Machine:
  - Inline validation on `blur` and on `submit`.
  - `isSubmitting` disables inputs and submit button, preventing double submission.
  - 10-second `AbortController` timeout for fetch requests.
  - On submission error or network timeout: user inputs remain **strictly preserved** in React state. An accessible error banner (`role="alert"`) displays the error with a prompt to email directly.
  - Web3Forms Response Check: Must inspect `data.success === true`.
- Demo Mode:
  - If `process.env.NEXT_PUBLIC_WEB3FORMS_KEY` is undefined or empty:
    - Displays a clearly marked notice banner: `"Demo mode — this was NOT sent. NEXT_PUBLIC_WEB3FORMS_KEY is not configured."`
    - Preserves input fields and does **not** trigger the success Stamp.
  - In production (`build:prod` / `OLI_PRODUCTION=1`): build guard fails if `NEXT_PUBLIC_WEB3FORMS_KEY` is missing or empty.
- Success State:
  - If Web3Forms returns `{ success: true }`, form is replaced by confirmation container announcing via `aria-live="polite"` and rendering the animated `Stamp` primitive:
    `"THANK YOU · RECEIVED [DRAFT]"`
    Copy: `"We reply within [NEEDED] working day(s). [DRAFT]"`

### 2. Contact Page (`app/contact/page.tsx`)
- Architectural Header:
  - Sheet tag: `SHEET A-05 · CONTACT`
  - Headline: `"Let's talk about your project. [DRAFT]"` in Instrument Serif.
- 2-Column Desktop / 1-Column Mobile Layout:
  - Left Column: Direct channels:
    - Real email: `<a href="mailto:olidesignstudio06@gmail.com">olidesignstudio06@gmail.com</a>`
    - WhatsApp: Plain non-link text `[NEEDED: WhatsApp number]`
    - Phone: Plain non-link text `[NEEDED: Phone number]`
    - Instagram: `[NEEDED: Instagram handle]`
  - Right Column: `<EnquiryForm />` (wrapped in `Suspense` for `useSearchParams`).
- Architectural TitleBlock: `sheetNumber="A-05"` `sheetTitle="Contact"` `scale="Scale 1:100"`.
