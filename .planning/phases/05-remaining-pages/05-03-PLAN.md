# Plan 05-03: Custom 404 Sheet & Page Transition Safety

## Goal
Build the custom 404 sheet (`app/not-found.tsx`, Sheet 404) matching `content.md`, and implement/evaluate the architectural ink line-wipe page transition (`components/layout/PageTransition.tsx`) against strict scroll restoration, pin measurement, and Lenis stability acceptance criteria.

## Requirements
- **PAGE-06**: Custom 404 sheet conforming to sheet aesthetic ("This sheet doesn't exist. Back to Home →").
- **PAGE-07**: Route change page transition (≤400ms ink line wipe, skipped under reduced motion and filter query clicks, ensuring native scroll restoration on Back, accurate ScrollTrigger pin measurement, and unbroken Lenis scrolling).

## Proposed Changes

### 1. Custom 404 Sheet (`app/not-found.tsx`)
- Structure:
  - Sheet Frame integration.
  - Sheet tag: `SHEET 404 · NOT FOUND`
  - Headline: `"This sheet doesn't exist."` in Instrument Serif (`clamp(36px, 5vw, 64px)`).
  - Subhead / Drafting Note: `"The drawing or specification you requested could not be located on this drawing board."`
  - Action Link: `"Back to Home →"` in DM Mono caps linking to `/`.
  - Architectural TitleBlock: `sheetNumber="404"` `sheetTitle="Not Found"` `scale="Scale N/A"`.

### 2. Page Transition Spike & Implementation (`components/layout/PageTransition.tsx`)
- Mount in `app/layout.tsx`:
  - Uses `usePathname()` to trigger only on real route changes (ignoring `/work?type=...` search param mutations).
  - SVG ink line wipe overlays the viewport with fixed position (`z-index: 999; pointer-events: none;`).
  - Animates a quick horizontal line draw and wipe in ≤400ms (`power2.inOut`).
  - Automatically skipped if `prefersReducedMotion()` is true.
- **Strict Acceptance Criteria:**
  1. **Scroll Restoration:** Browser Back and Forward buttons correctly restore previous scroll positions.
  2. **Pin Recalculation:** Pinned sections (Home Hero `+=300%`, Process `+=300%`, and Project Detail `+=150%`) measure and pin accurately after navigation without layout tearing or ghost spacers.
  3. **Lenis Continuity:** Lenis smooth scroll instance is not left in a paused or stalled state.
- **Contingency Rule:**
  If the transition component causes scroll jumping, pin offset miscalculation, or broken Back restoration during verification, drop the component and document the decision in `05-03-SUMMARY.md`.

## Verification Steps
1. Test 404 route: Navigate to `http://localhost:3005/non-existent-sheet`, verify status 404 and content matches "This sheet doesn't exist. Back to Home →".
2. Test route navigation across Home, Work, Process, About, Contact:
   - Verify line wipe completes in ≤400ms.
   - Verify filter clicks on `/work?type=interior` do NOT trigger transition wipe.
   - Test Back button navigation: verify scroll restoration and verify hero/process pins calculate exact positions without extra blank space.
3. Record visual appeal and transition feel as "awaiting user verification".
