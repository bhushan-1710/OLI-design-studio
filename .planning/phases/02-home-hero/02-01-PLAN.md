# Plan 02-01: Hero Elevation SVG & Primitives Relocation

## Goal
Build the isolated, typed architectural elevation SVG component (`components/sections/HeroElevation.tsx`) ported directly from `docs/reference/oli-hero.html`, containing all drawing layers (`.cl`, `.s1`, `.s2`, `.dim`, `.note`, wash fills, animated wash clip rect, and stamp), plus desktop-only pencil wobble filter (`feTurbulence`). Concurrently, relocate the Phase 1 UI primitives showcase from `app/page.tsx` to `app/dev/primitives/page.tsx` so the home page is prepped for the hero.

## Requirements
- **HERO-01**: Port approved `oli-hero.html` into a React client component preserving exact layer hierarchy (`.cl`, `.s1`, `.s2`, `.dim`, `.note`, wash group with clip rect, `.stamp`, `.hl-path`).
- **HERO-05**: Desktop-only pencil wobble filter (`feTurbulence` + `feDisplacementMap` on ≥769px, removed on mobile).
- **HERO-06**: Placeholder house elevation drawing structured with typed layers, ready to swap to real project trace when client assets arrive.

## Proposed Changes

### 1. Relocate UI Primitives Demo
- Create `app/dev/primitives/page.tsx` and move the Phase 1 primitives demonstration code from `app/page.tsx` into it.
- Keep the route accessible in development (`/dev/primitives`) for testing tokens, buttons, chips, stamps, dimension rules, and annotations.
- Clean `app/page.tsx` to prepare for mounting `<HeroSection />`.

### 2. Create `HeroElevation.tsx`
- Create `components/sections/HeroElevation.tsx` with:
  - SVG viewport: `viewBox="0 0 1100 520"`, `preserveAspectRatio="xMidYMid meet"`, `overflow="visible"`.
  - SVG `<defs>` containing:
    - `<filter id="pnp">`: `<feTurbulence type="fractalNoise" baseFrequency="0.03" numOctaves="2" result="noise" />` and `<feDisplacementMap in="SourceGraphic" in2="noise" scale="2.4" />`.
    - `<clipPath id="wash-clip-path">`: containing `<rect id="wash-clip" x="0" y="520" width="1100" height="0" />`.
  - Drawing group (`<g id="hero-drawing">`) with classes for wobble filtering:
    - `.cl`: Construction lines (`pathLength="1"`, `stroke-width: 0.9`, `opacity: 0.35`).
    - `.s1`: Primary contour lines (`pathLength="1"`, `stroke-width: 2.8`).
    - `.s2`: Secondary contour lines (`pathLength="1"`, `stroke-width: 1.7`).
    - `.dim`: Dimension lines and tick markers (`pathLength="1"`, `stroke-width: 1.4`).
    - `.note`: Handwritten notes with arrow paths.
  - Wash group: `<g id="washes" opacity="0.88" clipPath="url(#wash-clip-path)">` rendering watercolor fills (`--wash-sand`, `--wash-concrete`, `--wash-glass`, `--wash-timber`, `--wash-sage`, `--wash-shrub`, `--wash-slab`, `--wash-ground`).
  - Stamp group: `<g id="stamp" class="stamp">` with `<rect>` and `<text>` rotated -5°.
- In `styles/base.css` or scoped CSS module:
  - Desktop-only wobble filter:
    ```css
    @media (min-width: 769px) {
      .hero-art-drawing {
        filter: url(#pnp);
      }
    }
    @media (max-width: 768px) {
      .hero-art-drawing {
        filter: none;
      }
    }
    ```
  - Mobile art scaling:
    ```css
    @media (max-width: 820px) {
      .hero-art svg {
        width: 175%;
        margin-left: -37.5%;
        height: 40svh;
      }
    }
    ```
