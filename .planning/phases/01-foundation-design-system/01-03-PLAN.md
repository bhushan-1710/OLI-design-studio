       - Checks `window.matchMedia('(prefers-reduced-motion: reduce)').matches`.
       - Provides React hook `useReducedMotion()`.
    2. Create `lib/motion/lenis.ts`:
       - Registers ScrollTrigger with GSAP.
       - Initializes `Lenis({ lerp: 0.1, autoRaf: false })` if reduced motion is false.
       - Hooks `lenis.on('scroll', ScrollTrigger.update)`.

    3. Create `lib/motion/draw.ts`:
       - `draw(targets, { duration = 1, stagger = 0.1, ease = 'power2.out', delay = 0 })`: helper that ensures `pathLength="1"` is set and tweens `strokeDashoffset` from `1` to `0`.
    4. Create `lib/analytics.ts`:
       - Per D-03, export a typed event logger `trackEvent(name: 'enquiry_form_submit' | 'whatsapp_click' | 'email_click' | 'filter_click', properties?: Record<string, any>)`.
       - Dispatches custom DOM events or logs in development, ready for zero-friction GA4 / Plausible integration later.
  </action>
