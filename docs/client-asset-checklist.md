# Client Asset Checklist — OLI Design Studio

What we need from the studio, in priority order. The design depends on real project material, so items marked **Blocker** must arrive before the corresponding section can be built properly.

**How to ask:** send this as a shared folder request (Google Drive or similar). Ask for original files, not Instagram screenshots.

---

## 1. Projects (Blocker for Home, Work, project pages)

Choose **3–4 featured projects** that show range and finished quality. For each:

- [ ] Project name and discipline(s)
- [ ] Location and year
- [ ] Area or scale (optional but useful)
- [ ] 2–3 sentence brief: what the client wanted, what the site/constraints were
- [ ] **Cover photo** (landscape, highest resolution available)
- [ ] **8–15 photos** of the finished project (original files, JPG/HEIC/RAW fine)
- [ ] Photographer credit, or confirmation the studio owns the photos
- [ ] **Drawings:** any of the following, in the highest quality available
  - [ ] Hand sketches (photographed flat in even light, or scanned)
  - [ ] Plans, elevations, sections (PDF or CAD export)
  - [ ] 3D renders
  - [ ] Site / construction progress photos
- [ ] Client permission to publish (or confirmation that it's not needed)

*At least one featured project needs a clean elevation or plan: it becomes the hero drawing.*

## 2. Studio information (Blocker for Contact, About, SEO)

- [ ] WhatsApp number (business number if there is one)
- [ ] Phone number to display (optional)
- [ ] Email address that should receive enquiries (current: olidesignstudio06@gmail.com. Confirm.)
- [ ] Studio address or city, and the area they serve
- [ ] Working hours and typical reply time for enquiries
- [ ] Instagram handle confirmation, plus any other profiles (LinkedIn, Behance, Houzz)

## 3. Team and about

- [ ] Founder/team names and roles
- [ ] Portrait photos of each person (natural light, consistent framing)
- [ ] One-line bio each
- [ ] Studio philosophy in the studio's own words (even a rough paragraph or voice note)
- [ ] Year founded

## 4. Process

- [ ] How a project actually runs, from first meeting to handover (bullet points are fine)
- [ ] What the client decides vs what the studio decides at each stage
- [ ] Typical project duration ranges by discipline (optional)

## 5. Brand assets

- [ ] Logo files if any (vector preferred: SVG, AI, PDF)
- [ ] Any existing brand colours or fonts
- [ ] Whether the studio wants to keep the OLI wordmark as is or accept the hand-lettered logo from `design.md`

## 6. Decisions we need

- [ ] Do they want light/dark theme toggle visible in the nav?
- [ ] Is a Hindi or Marathi version needed at launch?
- [ ] Who will add projects after launch, and how often?
- [ ] Domain: do they control `olidesignstudio.in` DNS, and who can change it?
- [ ] Analytics preference (Plausible, GA4, or none)
- [ ] Any projects or content they do **not** want shown

## 7. Optional but valuable

- [ ] Client testimonials (with permission to name)
- [ ] Press mentions, awards, certifications (e.g. Council of Architecture registration)
- [ ] Short walkthrough videos of finished projects (MP4, under 30 s)

---

## Image requirements

| Use | Minimum size | Format |
|---|---|---|
| Cover photos | 2400 px wide | JPG/HEIC/RAW (we convert) |
| Gallery photos | 2000 px wide | JPG/HEIC/RAW |
| Portraits | 1200 px square | JPG |
| Drawings | PDF/vector, or 3000 px if raster | PDF, SVG, PNG |

**Not acceptable:** screenshots from Instagram, photos with watermarks from other studios, stock imagery.
